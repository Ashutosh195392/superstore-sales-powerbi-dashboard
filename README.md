# Super Store Sales Dashboard

An interactive Power BI dashboard analyzing Superstore sales and profit.

## Project Overview
This dashboard gives a quick view of sales performance across segments, categories, ship modes, payment modes and states.

## Tools Used
- Power BI
- DAX
- Excel

## Dashboard Features
- KPI cards for sales metrics
- Sales by Segment, Category, Sub Category
- Sales by Ship Mode and Payment Mode
- Sales and Profit trend over time
- Profit and Sales by State (map)

## Key Insights
- Office Supplies is the top category by sales
- Consumer is the largest segment (48%)
- Standard Class is the most used ship mode
- COD is the most used payment mode (43%)
